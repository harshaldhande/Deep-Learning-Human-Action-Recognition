## Overview

This project presents a Deep Learning-based Human Action Recognition System that classifies skateboarding actions from video sequences using Computer Vision and Neural Networks.

The system recognizes two skateboarding tricks:

- Ollie
- Kickflip

using deep learning techniques built with TensorFlow, Keras, and OpenCV.

The project demonstrates the complete pipeline from video preprocessing to model evaluation.

This research work was published in an IEEE Conference.
